# Java Learning

A collection of Java practice files and problem-solving exercises, focused on core DSA concepts and coding interview preparation.

## 🎯 Purpose

This repo tracks my daily hands-on practice while strengthening core data structures and algorithms — currently focused on **binary search and its variations**, including:
- Classic search on sorted arrays
- Search space reduction on rotated / infinite arrays
- "Binary search on the answer" pattern (e.g., allocation/split problems)

## 🛠️ Tech

- **Language:** Java
- Each file is a standalone, runnable class with a `main` method for quick testing.

## 🚧 Status

Actively updated daily as I work through more topics and problems (arrays, DP, and other DSA topics to follow).

## 📌 Notes

Solutions here are for personal learning and interview prep — not optimized production code, but working implementations with attention to edge cases (e.g., integer overflow in mid-point calculations, boundary conditions).
